# Product Investor Matching Report

## Executive Summary

This report matches five clients to investable products using portfolio hygiene, life-stage needs, product fitness scores, and the current market outlook. Each client receives one recommended product, funded by selling one existing position of similar risk/asset class. Expected returns use 5Y CAGRs where available; products without performance history use the catalog expected return. All trades preserve a >5% cash/liquidity buffer.
