# Proposal JSON Output Specification

This spec has been split into two phases:

| Phase | File | Scope |
|---|---|---|
| **Sprint 1** (current) | [proposal_JSON_output_s1.md](proposal_JSON_output_s1.md) | Minimal JSON — computation-required fields only. Scenario assumptions, funding source, recommended product ID/amount. All narrative stays in markdown. |
| **Sprint 2** (future) | [proposal_JSON_output_s2.md](proposal_JSON_output_s2.md) | Comprehensive JSON — adds narrative fields (executive summary, rationale, pros/cons, alternatives, risk characteristics, client needs, references). Enables full proposal reconstruction from JSON. |

**Do not add or maintain spec content in this file.** All updates should go to the appropriate phase file above.
